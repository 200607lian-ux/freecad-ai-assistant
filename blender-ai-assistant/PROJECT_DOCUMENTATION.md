## 项目概述

### 1.1 项目背景

传统的 3D 建模软件（如 Blender）学习曲线陡峭，需要掌握复杂的操作界面和建模技巧。本项目旨在通过**自然语言交互**降低 3D 建模的门槛，让用户能够用简单的文字描述来创建 3D 模型。

### 1.2 项目目标

- 🎯 **降低建模门槛**：让非专业用户也能快速创建 3D 模型
- 🤖 **AI 智能理解**：使用大语言模型理解自然语言建模指令
- 🔄 **实时预览**：在 Web 界面实时查看 3D 模型效果
- 💾 **多格式导出**：支持 9 种主流 3D 模型格式导出

### 1.3 应用场景

- 3D 打印前的快速建模
- 游戏资源快速原型制作
- 教学演示和概念验证
- Web3D 应用的模型生成

### 2.2 技术架构分层

#### **前端层** (`frontend/`)
- **框架**：原生 JavaScript + HTML5 + CSS3

  - 对话管理 (`app.js`)
  - 3D 模型查看器（支持旋转、缩放、平移）
  - 多格式导出控制面板

#### **后端层** (`backend/`)
- **Web 框架**：FastAPI
- **AI 模型**：DeepSeek-V4-Flash (通过阿里云百炼)
- **核心模块**：
  - `main.py` - FastAPI 主服务
  - `ai_agent.py` - 基础 AI 代理
  - `ai_agent_enhanced.py` - 增强版 AI 代理（多步推理）
  - `blender_client.py` - Blender 通信客户端

#### **Blender 层**
- **通信协议**：MCP (Model Context Protocol)
- **接口**：Python API
- **功能**：代码执行、场景管理、模型导出

## 核心功能

### 3.1 自然语言建模

**支持的建模指令：**

```
✅ 基础几何体创建
   "创建一个红色的立方体"
   "在位置(2, 0, 0)创建一个蓝色球体"
   "创建一个绿色的圆柱体，高度为3"

✅ 对象操作
   "把当前对象移动到(5, 5, 5)"
   "将球体旋转45度"
   "放大立方体2倍"

✅ 场景管理
   "删除所有物体"
   "查看场景信息"
   "隐藏当前对象"

✅ 材质和属性
   "设置对象颜色为红色"
   "添加金属材质"
   "设置透明度为0.5"
```

**AI 处理流程：**

1. **意图识别**：理解用户想要做什么
2. **参数提取**：提取颜色、位置、尺寸等参数
3. **代码生成**：生成对应的 Blender Python 代码
4. **执行验证**：在 Blender 中执行并返回结果

### 3.2 实时 3D 预览

- **自动刷新**：建模后自动导出 STL 并显示在预览器
- **交互控制**：
  - 🖱️ 左键拖动：旋转模型
  - 🔍 滚轮：缩放模型
  - 🖱️ 右键拖动：平移视角
- **视图控制**：
  - 🎯 重置视角
  - 🔲 线框/实体切换
  - 💾 下载 STL

### 3.3 多格式导出

支持 **9 种**主流 3D 模型格式：

| 格式 | 用途 | 特点 |
|------|------|------|
| **STL** | 3D 打印 | 最常用的打印格式 |
| **OBJ** | 通用交换 | 支持材质和纹理 |
| **FBX** | 游戏/动画 | 支持动画和骨骼 |
| **glTF** | Web3D | Web 标准格式 |
| **GLB** | Web3D | glTF 二进制版本 |
| **PLY** | 点云/扫描 | 支持顶点颜色 |
| **X3D** | Web3D | XML 格式 |
| **Collada (DAE)** | 影视制作 | 支持复杂场景 |
| **Alembic (ABC)** | 影视特效 | 支持动画缓存 |

**导出功能特色：**

- ✅ 一键导出，自动下载
- ✅ 30 秒超时保护
- ✅ 可随时取消导出
- ✅ 错误自动提示
- ✅ 空场景检测

### 3.4 智能错误处理

- **场景验证**：导出前检查是否有模型
- **超时控制**：30 秒自动取消，防止卡死
- **用户取消**：提供取消按钮，随时中断
- **错误提示**：友好的错误信息和解决建议

## 技术栈

### 4.1 前端技术

```
HTML5 / CSS3 / JavaScript (ES6+)
├── Three.js r128          # 3D 渲染引擎
├── OrbitControls          # 相机控制
├── STLLoader             # STL 文件加载

**关键技术点：**

- **Base64 编码**：高效的二进制数据传输
- **响应式布局**：自适应不同屏幕尺寸
- **状态管理**：导出状态、连接状态等

### 4.2 后端技术

```
Python 3.9+
├── FastAPI              # 异步 Web 框架
├── uvicorn              # ASGI 服务器
├── OpenAI SDK           # LLM API 调用
├── WebSocket           # 实时通信
└── asyncio             # 异步编程
```

**关键技术点：**

- **异步处理**：支持多客户端并发连接
- **流式响应**：支持多步推理的流式输出
- **错误重试**：网络故障自动重连
- **API 降级**：AI 不可用时使用规则引擎

### 4.3 AI 技术

**模型选择：** DeepSeek-V4-Flash

**选择理由：**
- ✅ 高性价比：0.14元/百万 tokens（输入）

- ✅ 代码能力强：擅长生成 Python 代码
- ✅ 中文友好：支持中文指令

## 安装部署

### 5.1 环境要求

```
操作系统: Windows 10/11, macOS 10.15+, Linux
Python: 3.9 或更高版本
Blender: 3.0 或更高版本
浏览器: Chrome 90+, Firefox 88+, Edge 90+
```

### 5.2 安装步骤

#### **Step 1: 安装依赖**

```bash
# 后端依赖
cd backend
pip install -r requirements.txt

# 主要依赖包：
# - fastapi==0.109.0
# - uvicorn==0.27.0
# - websockets==12.0
# - openai==1.10.0
```

#### **Step 2: 配置 AI 密钥**

```bash
# Windows PowerShell
$env:DASHSCOPE_API_KEY = "your-api-key-here"

# Windows CMD
set DASHSCOPE_API_KEY=your-api-key-here

# Linux/macOS
export DASHSCOPE_API_KEY=your-api-key-here
```

**获取 API Key：**
1. 访问 [阿里云百炼平台](https://bailian.console.aliyun.com/)
2. 注册/登录账号
3. 创建应用并获取 API Key

#### **Step 3: 配置 Blender MCP**

1. 打开 Blender
2. 编辑 → 偏好设置 → 插件
3. 搜索 "MCP" 或手动安装插件
4. 启用插件后，点击 "启动 MCP 服务器"
5. 确认端口为 9876

#### **Step 4: 启动系统**

```bash
# 启动后端服务
cd backend
python main.py

# 服务启动后会显示：
# ✓ Blender 连接成功
# ✓ AI 模式：使用 DeepSeek-V4-Flash 模型
# 服务地址: http://localhost:8000
```

#### **Step 5: 访问前端**

打开浏览器，访问：
```
http://localhost:8000
```

## 开发历程

### 8.1 技术难点及解决方案

#### **难点 1: Blender 通信不稳定**

**问题：**
- WebSocket 频繁断线
- 消息接收不完整
- 超时无响应

**解决方案：**
```python
# 实现重试机制
def send_command(self, cmd_type, params, retry_count=2):
    attempt = 0
    while attempt <= retry_count:
        try:
            # 发送命令
            self.socket.sendall(command_json.encode('utf-8'))
            # 接收响应
            response = self._receive_response(timeout=60.0)
            return response
        except Exception as e:
            if attempt >= retry_count:
                return None
            # 重连后重试
            self.connect()
            attempt += 1
```

#### **难点 2: 坐标系不一致**

**问题：**
- Blender 使用 Z-up 坐标系
- Three.js 使用 Y-up 坐标系
- 导致模型显示方向错误

**解决方案：**
```javascript
// 加载 STL 后旋转模型
geometry.rotateX(-Math.PI / 2);  // 绕 X 轴旋转 -90°
```

#### **难点 3: 某些格式导出失败**

**问题：**
- GLB、Collada 等格式导出报错
- 错误信息不明确

**解决方案：**
```python
# 简化参数，添加错误捕获
export_op = f"""
try:
    bpy.ops.export_scene.gltf(
        filepath=filepath,
        export_format='GLB',
        use_selection={selection_only},
        export_apply=True  # 只保留核心参数
    )
except Exception as e:
    print(f"GLB 导出失败: {{e}}")  # 打印具体错误
    raise
"""
```

#### **难点 4: AI 生成代码不稳定**

**问题：**
- 有时生成带解释的代码
- 代码格式不规范
- 包含非法导入

**解决方案：**
```python
# 优化 System Prompt
system_prompt = """
你是 Blender Python 专家。

要求：
1. 只输出纯 Python 代码，不要任何解释
2. 只使用 bpy 模块，不要导入其他库
3. 代码必须是完整可执行的
4. 使用 try-except 处理错误

示例：
用户: "创建红色立方体"
你:
```python
import bpy
bpy.ops.mesh.primitive_cube_add()
obj = bpy.context.active_object
mat = bpy.data.materials.new(name="Red")
mat.diffuse_color = (1, 0, 0, 1)
obj.data.materials.append(mat)
```
"""
```

### C. 常见问题 (FAQ)

**Q: AI 生成的代码执行失败怎么办？**

A: 尝试以下方法：
1. 简化指令描述
2. 分步执行复杂操作
3. 检查 Blender 控制台的错误信息
4. 查看 AI 返回的代码是否合理

**Q: 导出某些格式失败？**

A: 可能原因：
1. Blender 版本不支持该格式
2. 模型太复杂
3. 缺少相应的导出插件

建议优先使用 STL、OBJ、FBX 这些通用格式。

**Q: 3D 预览器显示不正常？**

A: 检查：
1. 浏览器是否支持 WebGL
2. 显卡驱动是否最新
3. 尝试刷新页面（Ctrl + Shift + R）

**Q: 如何提高 AI 生成质量？**

A: 技巧：
1. 使用具体的描述（颜色、位置、尺寸）
2. 一次只描述一个操作
3. 使用标准的几何术语
4. 参考示例指令格式
