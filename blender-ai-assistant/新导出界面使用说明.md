## 🚀 使用方法（超简单！）

### 3步完成导出

#### 第1步：创建模型
```
在右侧对话框输入：
"创建一个红色的立方体"
```

#### 第2步：选择格式
```
点击下拉菜单 [GLB (Web) ▼]
选择你需要的格式：
- STL (3D打印)
- OBJ (通用)
- FBX (游戏)
- GLB (Web) ← 推荐
- ... 等9种格式
```

#### 第3步：点击导出
```
点击 💾 按钮
文件自动下载！
```

**就是这么简单！** 🎉

## 🎨 格式选择指南

### 快速选择表

| 你要做什么？ | 选择格式 |
|------------|---------|
| 🖨️ 3D打印 | **STL** |
| 🌐 网页3D | **GLB** |
| 🎮 游戏开发 | **FBX** |
| 📦 通用交换 | **OBJ** |
| 🎬 影视制作 | **Collada** 或 **Alembic** |

### 不确定选什么？

**默认选GLB就对了！** ✅

GLB格式：
- ✅ Web友好
- ✅ 文件小
- ✅ 加载快
- ✅ 支持材质和颜色
- ✅ 几乎所有现代软件都支持

## 🔥 专业技巧

### 技巧1：快速连续导出
```
同一个模型，导出多种格式：

1. 选择 GLB → 点击 💾
2. 选择 FBX → 点击 💾
3. 选择 STL → 点击 💾

无需重新创建模型！
```

### 技巧2：默认格式
```
如果你总是用同一种格式：

不用每次都选择！
直接点 💾 就用默认的GLB格式
```

### 技巧3：检查下载
```
导出后检查：
1. 打开下载文件夹
2. 找到 blender_model_[时间戳].[扩展名]
3. 确认文件大小 > 0
```

## ❓ 常见问题

### Q: 下拉菜单在哪里？
**A**: 左上角，💾 按钮右边，有个 ▼ 标志

### Q: 默认是什么格式？
**A**: GLB (Web)，最通用的格式

### Q: 可以改变默认格式吗？
**A**: 目前不行，但会记住你上次的选择（即将推出）

### Q: 导出很慢怎么办？
**A**: 
1. 检查Blender是否响应
2. 模型是否太复杂
3. 参考[连接故障排查指南](CONNECTION_TROUBLESHOOTING.md)

### Q: 找不到下载的文件？
**A**: 
1. 检查浏览器下载文件夹
2. 文件名: `blender_model_[时间戳].[扩展名]`
3. 例如: `blender_model_1704672345678.glb`
